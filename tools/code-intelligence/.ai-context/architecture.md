## Key flows

- **Authentication** — `server/auth, client/stores`: JWT-based register/login. AuthService hashes with bcrypt and signs a JWT via JwtService; Passport JwtStrategy reading the Authorization header guards protected routes. Client pinia store persists token and restores profile on boot.
- **Payment** — `server/payment, server/reservations`: Reservation hold -> payment -> confirm pickup. Uses a CAS/idempotent confirmPayment that never resurrects completed payments; payment_status enum 'completed'.
- **AI Vision Search** — `server/ai, server/embedding`: searchByImage runs Gemini/OpenAI vision (fallback heuristic) to recognise food, maps tags to categories and scores active deals in Supabase.
- **Geo / Explore (realtime)** — `client/views-ex, client/composables, server/geo, server/socket`: ExploreView uses a leaflet map with useLocation watchPosition for live tracking and OSRM routing; WebSocket gateway pushes realtime order status.

For the deeper walkthrough of each flow see `tools/code-intelligence/docs/codebase-analysis.md`.
